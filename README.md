# 막시모 (Maximo) PS2 한글패치

PS2 일본판 **マキシモ (Maximo, SLPM-62127)** 용 비공식 한국어 패치입니다. 게임 안의 모든 일본어 텍스트(메뉴, 설정, 메모리 카드 메시지, 상점, 어빌리티 이름·설명, 스테이지 이름, 마녀의 키스 설명 등)를 한국어로 바꾸고, 자막 없이 일본어 음성만 나오던 동영상 6편에 한글 자막을 넣었습니다. 현재 배포판은 **v1.0 (2026-09-28)** 입니다.

[패치 다운로드](https://github.com/snake759494/maximo-korean-patch/releases/latest) · [기술 설명](docs/TECHNICAL.md) · [재빌드](docs/BUILD.md) · [변경 기록](CHANGELOG.md) · [권리 안내](RIGHTS.md)

릴리즈 첨부 파일은 **Maximo_PS2_KO_v1.0.xdelta 하나**입니다. 저장소에는 제작 소스·번역·검증 자료만 공개합니다. 원본 및 완성 디스크 이미지, 추출한 실행파일·텍스처·동영상, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub 가 자동 생성하는 Source code ZIP/TAR 는 저장소 소스의 압축본이며 게임 파일이 아닙니다.

> ⚠️ `translation/` 폴더(특히 `translation/movie/`)에는 게임 대사와 동영상 자막 전문이 들어 있어 **줄거리 스포일러**가 포함됩니다. 게임을 먼저 즐기실 분은 열어 보지 마세요. 이 README 에는 줄거리 내용을 적지 않았습니다.

## 게임 소개 및 대상 버전

「マキシモ」는 캡콤이 2001년 PS2로 낸 3D 액션 게임입니다. 『마계촌』 시리즈의 계보를 잇는 작품으로, 기사 막시모가 검과 방패를 들고 묘지·늪·빙하 등을 누비며 싸웁니다. 5개 월드, 각 월드의 거점 광장과 여러 스테이지·보스로 구성되어 있습니다.

이 패치는 **PS2 일본판 SLPM-62127 의 BIN/CUE (MODE2/2352, 트랙 1개)** 에만 적용합니다. 파일 이름보다 아래 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

### Windows 에서 원본 확인

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Maximo (Japan).bin'
```

위 표와 다르면 적용을 중단하세요. ISO(2,048 바이트 섹터)로 변환한 이미지나 CHD·CSO 에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Maximo_PS2_KO_v1.0.xdelta` 를 받습니다.
2. xdelta3 패치를 지원하는 도구의 **Apply Patch** 기능을 엽니다.
3. **Patch** 에 xdelta 파일, **Source File** 에 해시가 일치하는 원본 `.bin` 을 선택합니다.
4. **Output File** 에 새 파일명(예: `Maximo (Japan) (Korean).bin`)을 지정합니다.
5. 원본 `.cue` 를 복사해 새 이름(`Maximo (Japan) (Korean).cue`)으로 바꾸고, 메모장으로 열어 `FILE "…"` 안의 파일명을 새 `.bin` 이름으로 고칩니다.

xdelta 는 호환성을 위해 2차 압축과 파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Maximo (Japan).bin' '.\Maximo_PS2_KO_v1.0.xdelta' '.\Maximo (Japan) (Korean).bin'
```

해시를 자동 검사하고 `.cue` 까지 만들어 주는 도구도 있습니다(Python 3 + xdelta3 필요, 기존 출력 파일은 덮어쓰지 않음).

```powershell
python tools/apply_release.py --xdelta '.\xdelta3.exe' --source '.\Maximo (Japan).bin' --patch '.\Maximo_PS2_KO_v1.0.xdelta' --output '.\Maximo (Japan) (Korean).bin'
```

### PCSX2 에서 실행

새 `.cue` 를 여세요. 원본판의 세이브 스테이트는 불러오지 마세요(실행파일 내용이 다름). 이어 하기는 게임 안 메모리 카드 저장을 쓰세요. 메모리 카드 세이브 데이터는 원본판과 호환됩니다(저장 형식은 건드리지 않음).

### 번역 원칙

- 기계번역 없이 문맥과 장면을 보고 직접 번역했습니다.
- 모든 문장은 원문 줄 폭을 기준으로 넘치지 않게 맞췄습니다(`tools/qa_width.py`).
- 고유명사: 막시모 / 소피아 공주 / 마왕 아킬리 / 사신 그림 / 마녀 레노어·맘바 마리·오로라 리·세포니 / 데스 코인 / 마법 협의회.
- 어빌리티 이름은 원작처럼 외래어(그레이트 소드, 실드 샷, 둠 스트라이크 등)로, 스테이지 이름은 일본판 이름의 뜻을 살려 옮겼습니다.
- 동영상 자막은 faster-whisper(large-v3)로 받아쓴 뒤 설정을 달리한 두 결과와 장면 화면을 대조해 오인식을 바로잡았습니다.

### 번역하지 않은 것

- 원래 영어로 되어 있는 이미지: `SAVE`(세이브 포인트 조형물), `Loading`, 영문 로고, 저작권 화면, 스태프 크레딧 이미지.
- 갤러리 원화 속 서명·날짜, 배경 장식의 룬 문자.

## 알려진 한계

- 컨티뉴 화면의 "다음 컨티뉴에는 개 필요하다!"는 원문처럼 빈칸 자리에 숫자가 따로 찍히는 구조입니다.
- 동영상은 다시 인코딩했기 때문에 원본보다 화질이 아주 조금 떨어질 수 있습니다(대부분 구간은 가장 고운 양자화로 인코딩).
- 동영상 자막은 음성 인식을 거쳐 만들었으므로, 들리는 대사와 미세하게 다른 곳이 있을 수 있습니다. 발견하면 이슈로 알려 주세요.
- 인게임 확인은 PCSX2 v2.2.0 으로 했습니다. 실기에서의 동작은 확인하지 못했습니다.
